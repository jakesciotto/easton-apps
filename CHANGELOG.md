# Changelog

All notable changes to this project are documented in this file. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses
[Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-10-26

### Added

- Launcher page with chiclets for Leaderboard, Duals, Easton+ and Easton+ Staging.
- Connect section for the Easton MCP server with cards for Claude, ChatGPT and Claude Code.
- The eastonbjj.com theme, and a static export for Vercel.
- `noindex` through the robots meta tag, `robots.txt` and the `X-Robots-Tag` header.
- CI with format, lint, typecheck, build and gitleaks.
